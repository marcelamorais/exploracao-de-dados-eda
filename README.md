# exploracao-de-dados-eda
📊 Exploração de Dados (EDA)
Esse projeto foi desenvolvido em Python com o objetivo de aplicar técnicas de limpeza, transformação, integração de bases e geração de métricas para apoio à tomada de decisão com dados.
O projeto simula um cenário real de dados relacionados a locações de veículos, clientes, veículos e emissões de CO₂, seguindo uma lógica próxima a um pipeline ETL.

🎯 Objetivo do Projeto:
- Realizar a limpeza e padronização dos dados.
- Integrar múltiplas bases utilizando merge.
- Calcular métricas de negócio como: duração da locação, receita total por locação, emissão de CO₂ por locação, praticar Exploração de Dados (EDA) utilizando pandas.

🛠️ Tecnologias usadas:
- Git & GitHub
- Google Colab / Jupyter Notebook
- Pandas / Python
